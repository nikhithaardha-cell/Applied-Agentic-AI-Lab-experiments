## About

This repository contains the laboratory experiments completed as part of the **Applied Agentic AI** course.

The experiments cover Text-to-SQL, Retrieval-Augmented Generation (RAG), prompt chaining, and SQL agents with database tool use.

---

**Topic:** Build an end-to-end LLM workflow with retrieval and query generation.

**Technologies:**
- Python
- SQL
- SQLite
