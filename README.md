# Applied Agentic AI Laboratory

This repository contains the laboratory experiments for the Applied Agentic AI course.

## Experiments

### Lab 1 – Text-to-SQL Workflow

Converts natural language questions into SQL queries and retrieves information from a database.

### Lab 2 – RAG-Based Question Answering System

Retrieves relevant information from a knowledge base and generates answers using a RAG-based approach.

### Lab 3 – Prompt Chaining for Summarization

Uses multiple processing stages to extract key points, organize information, and generate a final summary.
