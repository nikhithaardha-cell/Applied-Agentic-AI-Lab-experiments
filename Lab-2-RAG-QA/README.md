# Lab 2 – RAG-Based Question Answering System

## Aim

To implement a Retrieval-Augmented Generation (RAG) based Question Answering System that retrieves relevant information from a knowledge base and generates an appropriate answer.

## Objective

To understand document indexing, information retrieval, and answer generation using a RAG-based approach.

## Description

Retrieval-Augmented Generation combines information retrieval with answer generation. The system first retrieves relevant information from a knowledge base and then uses the retrieved information to generate an answer.

## Workflow

Documents
↓
Document Processing
↓
Indexing
↓
User Question
↓
Information Retrieval
↓
Relevant Information
↓
Answer Generation
↓
Final Answer

## Technologies Used

- Python
- Scikit-learn
- TF-IDF
- Natural Language Processing
- Information Retrieval
- RAG

## Example

### Input

What is cybersecurity?

### Retrieval

The system searches the knowledge base and retrieves information relevant to the question.

### Output

The retrieved information is used to generate an appropriate answer.

## Result

The RAG-based Question Answering System successfully retrieves relevant information from the knowledge base and generates an answer.

## Conclusion

This experiment demonstrates the basic working of a Retrieval-Augmented Generation system.
